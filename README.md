# ZipLink

A production-ready URL shortener built with FastAPI and PostgreSQL.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker (planned)
- Redis (planned)

## Features

- URL shortening
- Redirects
- Click analytics (planned)
- Authentication (planned)
- Rate limiting (planned)
